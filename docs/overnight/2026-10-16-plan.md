# Overnight build run, 2026-10-16: plan

Goal: dictation that lands in the right place every time, knows the app you're in and formats for
it, plus the 1.0 launch work that doesn't need the owner's machine. Scope is dictation only,
English first. Red lines from the brief apply to every workstream (public sources only, licenses,
no secrets or irreversible actions, no new tracking, never lose a dictation).

## How it runs

- One orchestrator (this session) and a fleet of workers, each in its own git worktree on its own
  branch, one PR per workstream.
- Gates: `macos` (swift build + swift test on macos-15), `windows` (typecheck, vitest, build,
  Playwright E2E, packaging) and `windows-upgrade` CI jobs. Swift can't build on the Linux run box,
  so Swift work is verified only through CI logs.
- A PR merges (squash) only when all three jobs are green and a reviewer that didn't write the code
  has reviewed it adversarially (Opus and Sonnet reviewers; Codex isn't available in the cloud, so
  Opus takes its slot). Risky PRs (identity, signing, migration, data deletion, release scripts,
  user data on disk) wait for the owner.
- Shared files (`AppDelegate.swift`, `TextInserter.swift`, `windows/src/main/index.ts`, settings
  models) belong to one workstream at a time. B1 holds them first; the wiring workstream takes them
  after B1 merges.
