## DISMISSED

- **Script injection via session ids or the app id**: ids reach PowerShell only as validated base64 (`encodeSessionIds`, `[A-Za-z0-9+/=,]`), and `ownAppId` is checked against `OWN_ID` before interpolation. No raw text enters a script.
- **Media work delaying the recording start or the paste**: `recordingStarted`/`recordingEnded` only chain a promise; effects run in a separate `PowerShellHost` process from the delivery host, and each request has its own timeout and queue.
- **Media failure becoming a dictation error**: `DictationService.recordingEvent` catches sync throws and logs under `media`; the policy catches every effect rejection and even a throwing `log`.
- **Pausing twice on a back-to-back start**: `pausePlayingScript` skips anything not `Playing`, so the second pause is a no-op, and `resumeHeld` skips while a recording is live.
- **Resume waiting for transcription**: `recordingEvent('end')` fires in `stopRecording` before `run(session, process)`, and in `cancel`/`recorderFailed`/the start failure before any transcription.
- **Resuming media the user had already paused**: only sessions that accepted the pause are remembered, and the resume script re-checks `Paused`.
- **Our own sound cues being paused**: cues play through `Media.SoundPlayer` in the delivery host (winmm), not a GSMTC session; the `ai.useful.voice` skip is extra safety.
- **Startup settings or an old settings file flipping the feature on wrongly**: `normaliseSettings` keeps only real booleans and defaults to on for a missing key.
- **Unhandled rejection from `warm()` or quit**: `PowerShellHost.start()` never rejects, `enqueue` catches every failure, and the shutdown chain never rejects.
- **A stuck media queue**: each host request has a timeout, a dead host is restarted and then given up on with one-shot fallback, and `dispose` rejects pending requests.
- **The media host leaking past quit**: `dispose()` kills it and nulls the module singleton.
- **`FakeMedia`/`setMedia` reaching users**: the hooks are installed only under `--e2e`.
- **Quit blocking on a slow player**: the 2.5 s race bounds it (only the cleared-`held` consequence is reported above).
